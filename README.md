# Statistical Modelling of Financial Tail Risk (S&P 500)

## 📌 Project Overview
[cite_start]Modelled financial tail risk by applying the **Pareto distribution** to 150+ years of S&P 500 extreme loss data (1871-2023)[cite: 12]. This project focuses on estimating the 'tail index' parameter to understand the probability of extreme market events.

## 🧮 Mathematical Methodology
[cite_start]Implemented key statistical estimators to calculate the crucial tail index parameter[cite: 13]:
* **Maximum Likelihood Estimation (MLE):** Used for robust parameter estimation under extreme value theory.
* **Method of Moments (MOM):** Applied as an alternative estimation technique for comparison.

## 🧪 Validation & Simulation
* [cite_start]**Monte Carlo Simulations:** Conducted simulations to rigorously evaluate estimator quality and bias[cite: 14].
* [cite_start]**Efficiency Analysis:** Approximated **Mean Squared Error (MSE)** and validated variance against the **Cramer-Rao Lower Bound (CRLB)**[cite: 14].
