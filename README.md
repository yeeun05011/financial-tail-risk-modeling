# Statistical Modelling of Financial Tail Risk (S&P 500)

## 📌 Project Overview
Modelled financial tail risk by applying the **Pareto distribution** to 150+ years of S&P 500 extreme loss data (1871-2023). This project focuses on estimating the 'tail index' parameter to understand the probability of extreme market events.

## 🧮 Mathematical Methodology
Implemented key statistical estimators to calculate the crucial tail index parameter:
* **Maximum Likelihood Estimation (MLE):** Used for robust parameter estimation under extreme value theory.
* **Method of Moments (MOM):** Applied as an alternative estimation technique for comparison.

## 🧪 Validation & Simulation
* **Monte Carlo Simulations:** Conducted simulations to rigorously evaluate estimator quality and bias.
* **Efficiency Analysis:** Approximated **Mean Squared Error (MSE)** and validated variance against the **Cramer-Rao Lower Bound (CRLB)**.

## 🛠 Tech Stack
* **Language:** R
* **Domain:** Extreme Value Theory (EVT), Financial Risk Management, Statistical Inference
